## 1 数据源管理


### 1.1 SQL Server低版本中文乱码如何解决


**问题**：SQL Server 低版本数据源出现中文乱码，添加 charset=GBK 等配置无效怎么办？


**处理方式**：


请区分「连接失败」与「中文乱码」两类问题：


1. **连接失败（连不上旧版 SQL Server）**：数据源配置中提供「兼容低版本」选项。存量数据为保证可用性默认选中，新建时默认不选中。若连接失败，可按需勾选。注意：勾选「兼容低版本」后无法设置编码，**不能**用来解决乱码。
2. **中文乱码**：一般不要依赖「兼容低版本」。`nvarchar` 类型通常不存在乱码；若为 `varchar` 类型且排序规则为 `Chinese_PRC`，可在额外连接参数中添加 `charset=GBK`。另请注意：`varchar` 与 `nvarchar` 不可混用。


若已勾选「兼容低版本」导致无法设置编码，可先关闭该选项后再配置 `charset=GBK`（需确认关闭后仍能正常连接）。
